## 2 · Secrets — decide each one

```bash
# Onboarding emails to the 6 waiting businesses. OFF until you set this.
# Read worker/bizonboard.mjs first; nothing sends without it.
printf '%s' 'on' | npx wrangler secret put BIZ_ONBOARD_EMAIL --config wrangler.app.jsonc

# The weekly business note. Also off by default.
printf '%s' 'on' | npx wrangler secret put BIZ_WEEKLY_EMAIL --config wrangler.app.jsonc

# Stop the mail self-test writing to num_health every 5 minutes.
npx wrangler secret delete MAIL_SELFTEST --config wrangler.app.jsonc

# Optional: separate the verification HMAC from ADMIN_KEY (it falls back to it).
printf '%s' "$(openssl rand -hex 32)" | npx wrangler secret put BIZ_VERIFY_SECRET --config wrangler.app.jsonc
```

## 3 · Ship the Worker

```bash

# merge to main, then from main:
npm run release:stage "biz approval, verification, dashboard v1.1.0, apple sign-in"
npm run release:ship 10
npm run release:ship
```

Rollback: `npm run release:rollback`.

```bash

npx cap open ios     # Archive → Distribute. Build number is already 3.
```

Before submitting, on an **iPad**:

1. Tap the profile picture — a picker must open, not a crash.
2. **Confirm the "Sign in with Apple" button appears.** If the native plugin
   fails to register the button hides itself silently, and a silent hide is
   another 4.8 rejection on a fix that exists.
3. Record the account-deletion flow for Apple.
4. Re-check App Review Information *after* upload — that panel has emptied
   itself before.
5. Paste `APP_REVIEW_REPLY_1.0.3.md` into Resolution Center, attach the
   recording, submit.

**Order matters:** the Worker must be live before a reviewer opens the build,
or `POST /api/social/apple` 404s and 4.8 fails on a fix that exists.
