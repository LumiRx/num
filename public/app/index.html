Add to Home Screen

  1. Tap Open Num above — it must be in Safari, not another browser.
  2. Tap the Share button (the square with the arrow pointing up).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add. Num now opens full screen, like any other app.

Install

  1. Tap Open Num above in Chrome.
  2. Tap the ⋮ menu, top right.
  3. Tap Install app (or Add to Home screen).
  4. Confirm. Num now opens full screen, like any other app.

It's a real install — an icon on your home screen, full screen, works offline for everything that doesn't need the network. It just doesn't need an app store to get there.
